# 家事きろく

やった家事にチェックすると「済」のはんこが押される、スマホ用の家事チェックアプリ。

- **毎日そうじ**：その日の分をチェック。全部終わると「ぜんぶ済」
- **週一**：今週（月〜日）の分をチェック
- **月一**：「第2土曜日」「毎月15日」のようにやる日を決めておくと、カレンダーに表示される
- 記録はそのスマホのブラウザの中（localStorage）に保存される。「項目の設定」からバックアップと復元ができる
- ホーム画面に追加するとアプリのように全画面で開き、オフラインでも使える

## ファイル

- `index.html`：アプリ本体（HTML・CSS・JS がこれ1つに入っている）
- `manifest.webmanifest`・`sw.js`・`icons/`：ホーム画面に追加して使うためのファイル

## 使い方

フォルダごと Netlify（https://app.netlify.com/drop）や GitHub Pages などに置き、スマホのブラウザで開いて「ホーム画面に追加」する。

ローカルで確認するとき：

```bash
python3 -m http.server 8765
```
